# exoticcode-cli

## poradnik jak pobrac

potrzebujesz **Node.js 20+**.
> tu pobierzesz https://nodejs.org/en
> 
### Windows

otwórz **PowerShell** i wpisz:

```powershell
irm https://raw.githubusercontent.com/mikusiekq/exoticcode-cli/main/install.ps1 | iex
```

### Linux / macOS

odpal terminal i wpisz:

```bash
curl -fsSL https://raw.githubusercontent.com/mikusiekq/exoticcode-cli/main/install.sh | bash
```

## Odpalenie

po instalacji:

```bash
exoticcode
```

pod tą komendą masz info jak odinstalowac itp.
```bash
exoticcode -h
```
